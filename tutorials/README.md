## Conformance notes

- **Standalone carrier (ST1–ST8, SRC4, SRC12):** no clone, repository install or repository import in the kernel; the carrier cell writes and hash-verifies every carried file, and the `weights` stage asserts the carried manifest against the package's pinned identity before staging.
- **Isolated environment (RUN1, RUN10, ENV1, ENV2, ENV6; §25.13):** no cell pip-installs into the kernel; kernel cells import only the standard library, `IPython.display` and (for the BYOD upload) `google.colab`. The install cell refuses the `uv` wheel unless its size and SHA-256 match, builds a managed CPython 3.12.12 environment, installs the carried lock with `--require-hashes --only-binary :all:`, removes `PYTHONPATH` and credentials from the stage environment and sets `MPLBACKEND=Agg`; figures are written to files and displayed by the kernel. The check cell refuses non-Linux-x86_64 platforms.
- **Model acquisition (MOD1–MOD9):** the bundle is fetched from its immutable object generation only, written after its size and SHA-256 match, and every member is verified before each load; no pickle, no remote code.
- **Validation (VAL1–VAL8, DAT12, DAT19):** ceilings printed first; four refusal probes and one reported conversion in the default path; BYOD refusals name the file and rule.
- **Evaluation (EVAL1–EVAL15, UNC1–UNC4):** NME over 14 annotated points with the annotated IOD, detection and failure rates, two leave-one-out baselines, per-point errors, groups with `n`, a seeded bootstrap interval for the mean; blendshape scores labelled uncalibrated and checked only as a paired sanity check with one stated expectation; every number labelled tutorial / sanity evidence.
- **BYOD (DAT10–DAT19):** `USE_BYOD = False` by default; `BYOD_PATH` bypasses the upload dialog (EXE2); same validation, inference and output contract; faces flagged as personal and biometric data; nothing leaves the runtime.
- `tools/validate_release_assets.py` performs source validation only. It does not satisfy the clean-runtime execution requirement.
